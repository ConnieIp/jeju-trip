# 카페 쉼표 Cafe Comma

## 基本資訊
- 地區：西部 - 翰林/挾才
- 類型：Cafe
- 韓文地址：제주특별자치도 제주시 한림읍 한림로 359
- 英文地址：359 Hallim-ro, Hallim-eup, Jeju-si, Jeju-do
- 電話：010-9657-2204
- 營業時間：每日 09:00 - 21:00
- 公休日：全年無休
- 停車：可停車（挾才海水浴場停車場）
- 寵物：可攜帶寵物
- 幼兒：可攜帶幼兒

## 特色
- 挾才海水浴場旁的海景咖啡廳
- 可眺望飛揚島的絕美海景
- 1-3樓皆為咖啡空間
- 3樓及戶外設有吊床、鞦韆等網美打卡點
- 巴厘島風格的放鬆氛圍

## 推薦菜單
- 飲品：7,000-8,000韓元
- 招牌麵包：13,000韓元
- 奶油焦糖拿鐵
- 提拉米蘇
- 季節特調飲品

## 備註
- 建議停留：1-1.5小時
- 3樓拍照效果最佳
- 可結合挾才海水浴場行程安排
