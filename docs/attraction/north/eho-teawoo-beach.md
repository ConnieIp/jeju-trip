# 梨湖木筏海邊 이호테우해변 Eho Teawoo Beach

## 基本資訊
- 地區：北部 - 濟州市
- 類型：海邊 / 景點
- 地址：濟州特別自治道濟州市伊湖一洞375-43
- 電話：064-712-5223
- 停車：可停車（이호테우등대 주차장）

## 特色
- 濟州市區最近的海灘，距離機場極近
- 標誌性的馬形燈台（말등대）：紅色與白色兩座
- 以濟州矮馬為靈感設計的12公尺高燈台
- 熱門IG打卡景點，適合拍攝人生照片
- 日落時分景色尤佳

## 活動
- 沙灘散步
- 海景攝影
- 觀賞日落
- 防波堤漫步

## 備註
- 建議停留：30分鐘-1小時
- 距離濟州機場車程約10分鐘
- 可結合附近景點安排：機場附近咖啡廳、梨湖海水浴場
- 夜間燈台會亮燈，別有風味
