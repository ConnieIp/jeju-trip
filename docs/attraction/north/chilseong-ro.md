# 七星路 칠성로 Chilseong-ro

## 基本資訊
- 地區：北部 - 濟州市中心
- 類型：購物街 / 景點
- 地址：濟州特別自治道濟州市觀德路13街12
- 電話：064-721-7890
- 營業時間：各店鋪不同

## 特色
- 濟州歷史最悠久的傳統商業街
- 被譽為「濟州的明洞」，時尚購物第一街
- 街名源自北斗七星，設有星形照明裝飾
- 復古與潮流並存的拍照熱點
- 定期舉辦節慶活動與市集

## 活動
- 購物（服飾、美妝、生活用品）
- 美食街用餐
- 拍照打卡（復古/潮流裝置藝術）
- 參與季節性活動與慶典
