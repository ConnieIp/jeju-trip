# 伊丹潤博物館 ITAMI JUN Museum (이타미준미술관)

## 基本資訊
- 地區：西北部
- 類型：博物館 / 建築
- 韓文地址：제주특별자치도 제주시 한림읍 용금로 906-10
- 英文地址：906-10 Yonggeum-ro, Hallim-eup, Jeju-si, Jeju-do
- 網站：[ArchDaily](https://www.archdaily.com/1036765/itami-jun-museum-itm-yooehwa-architects) / [Korea Travel Guru](https://koreatravel.guru/p/itami-jun-museum/)

## 開放時間
- 週二–週日：10:00–18:00
- 最後入場時間：17:00
- **週一休館**
- 1月1日休館
- 開放時間可能因內部情況調整，建議來電確認

## 門票費用
- 成人：₩26,000

## 特色
- 紀念韓裔日本建築師伊丹潤（Itami Jun, 1946–2011）
- 由女兒為父親建造的博物館
- 建築本身即是一件藝術作品
- 透過建築圖稿、香氛、茶與音樂呈現伊丹潤的哲學
- 極簡主義建築風格，光影與空間的對話
