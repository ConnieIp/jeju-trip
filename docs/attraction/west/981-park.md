# 9.81 Park (9.81 파크 제주)

## 基本資訊
- 地區：西北部
- 類型：景點 / 體驗
- 韓文地址：제주특별자치도 제주시 애월읍 천덕로 880-24
- 英文地址：880-24 Cheondeok-ro, Aewol-eup, Jeju-si, Jeju-do
- 電話：1833-9810 (09:20–18:20)
- 網站：[9.81 Park 官網](https://981park.com/?lang=en) / [Visit Korea](https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=113070)
- 建議遊覽時間：09:30 開門首批

## 開放時間
- 09:00–18:00（依月份可能調整，請以官網為準）
- 全年無休

## 門票費用
- 依活動項目不同收費
- 建議事先於 Klook / Trip.com 購票可享折扣

## 特色
- 韓國首座非機動（重力驅動）賽車主題公園
- 無重力賽車體驗
- 位於涯月海灘與漢拿山之間
- 海景與山景
- 早場排隊時間短
- 秋高氣爽體感最舒服

## 備註
- 建議停留：2–2.5 小時
- 平日人潮較少
- 假日需預留排隊時間
