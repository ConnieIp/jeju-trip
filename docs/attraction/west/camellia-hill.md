# 山茶花之丘 Camellia Hill (카멜리아힐)

## 基本資訊
- 地區：西北部
- 類型：自然景點 / 花園
- 韓文地址：제주특별자치도 서귀포시 안덕면 병악로 166
- 英文地址：166 Byeongak-ro, Andeok-myeon, Seogwipo-si, Jeju-do
- 電話：+82-64-792-2002
- 網站：[Camellia Hill 官網](http://www.camelliahill.co.kr) / [Visit Korea](https://english.visitkorea.or.kr/svc/whereToGo/locIntrdn/rgnContentsView.do?vcontsId=76804)

## 門票費用
- 成人：₩12,000
- 另有兒童、老人優惠票

## 特色
- 亞洲最大的山茶花植物園，6,000 株山茶花樹
- 人工瀑布
- 花園步道
- 夏季繡球花、冬季山茶花
- 粉紅亂子草（Pink Muhly）— 秋季最佳
- 早秋花卉

## 備註
- 建議停留：1–1.5 小時
- 注意：山茶花之丘（카멜리아힐）與山茶花森林（동백포레스트）是不同的景點
- 位於西歸浦市安德面，與 Osulloc 茶博物館同區域
