# 翰林邑仙人掌村 (Wolryeong-ri Cactus Village / 월령리선인장군락지)

## 基本資訊
- 地區：西北部 - 翰林邑
- 類型：自然景點 / 天然紀念物
- 韓文地址：제주특별자치도 제주시 한림읍 월령리 359-3
- 英文地址：359-3 Wolryeong-ri, Hallim-eup, Jeju-si, Jeju-do
- 網站：[Visit Jeju](https://m.visitjeju.net/zh/detail/view?contentsid=CONT_000000000500494)
- 建議遊覽時間：14:30 - 15:30

## 開放時間
- 全年無休（戶外村落，無固定開放時間）
- 建議白天前往

## 門票費用
- 免費

## 特色
- 天然紀念物第 429 號
- 韓國唯一的野生仙人掌群落
- 位於翰林邑月嶺里海邊的村莊
- 多種仙人掌沿著海邊石牆自然生長
- 濟州偶來步道第 14 路線沿線
- 韓綜《姜食堂》拍攝地
- 西海岸仙人掌原生群落步道

## 備註
- 建議停留：30–60 分鐘
- 可結合挾才海水浴場安排同一天
- 沿村莊步道散步即可，不需門票
