# 香水博物館 Musee de Parfum (무제드파팡)

## 基本資訊
- 地區：西南部 - 西歸浦 / 城山
- 類型：博物館 / 體驗
- 韓文地址：제주특별자치도 서귀포시 성산읍 삼달로 239
- 英文地址：239 Samdal-ro, Seongsan-eup, Seogwipo-si, Jeju-do
- 網站：[Klook](https://www.klook.com/activity/144279-jeju-perfume-museum-one-day-class/) / [Trazy](https://www.trazy.com/fr-FR/experience/detail/perfume-museum-admission-ticket-perfume-making-experience-in-jeju)

## 開放時間
| 日 | 開放時間 |
|----|----------|
| 週一 / 週三 / 週五 | 12:00–17:00 |
| 週二 | 公休 |
| 最後入場 | 16:00 |

**香水製作體驗課程時間：** 14:00 / 15:30（每堂 45 分鐘）

## 門票費用
- 參觀 + 香水製作體驗：費用依方案而異
- 建議事先於 Klook / KKDay 預約

## 特色
- 展示超過 2,000 款全球香水
- 親手製作個人專屬香水體驗課程（45 分鐘）
- 位於城山邑柑橘園旁
- 以成為「韓國的格拉斯（Grasse）」為願景
- 香水展覽
- 香水製作一日課程

## 備註
- 建議停留：1.5–2 小時（含課程）
- 建議事先預約香水製作課程
- 位於城山區域，可結合城山日出峰安排
- 建議使用計程車或自駕前往
- 參考連結：https://www.seoultravelpass.com/zh-TW/products/1565-濟州-香水博物館-muzede-papang-展覽-製作香水一日課程
