# 山君不離 (Sangumburi / 산굼부리)

## 基本資訊
- 地區：東部
- 類型：自然景點 / 天然紀念物
- 韓文地址：제주특별자치도 제주시 조천읍 비자림로 768
- 英文地址：768 Bijarim-ro, Jocheon-eup, Jeju-si, Jeju-do
- 電話：+82-64-783-9900
- 網站：[山君不離官網](http://www.sangumburi.net) / [Visit Korea](https://big5chinese.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=93304)
- 建議遊覽時間：10:00 - 11:30

## 開放時間
| 季節 | 開放時間 |
|------|----------|
| 夏季 | 09:00–18:40 |
| 冬季 | 09:00–17:40 |

## 門票費用
- 成人：₩6,000
- 學生 / 老人：₩3,000

## 特色
- 天然紀念物第 263 號，火山口地形
- 周長約 2 公里，底部平坦如盆地
- 十月底是銀白色紫芒花盛開期（10月–1月最佳）
- 上午光線極佳，適合攝影
- 步行環繞約 40 分鐘–1 小時
- 韓國電影《戀風戀歌》（張東健、高素英）外景地

- 建議停留：1–1.5 小時
